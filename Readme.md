## Описание
Это приложение предназначено для воспроизведения бага в UI EvotorPos


### Баг POS, при назначении скидки, через активити запущенную через сервис(с правом RECEIPT_DISCOUNT_REQUIRED_EVENT )
1. Установите приложение на терминал, укажите uuid приложения и пакет
2. добавьте в чек позицию на 1000 рублей
3. нажмите кнопку к оплате (выберите сервис ReceiptDiscountService)
4. перейдите к оплате, на экране отображиться сумма 1000 рублей
5. нажмите оплатить, откроется окно с верной суммой 900 рублей


Если запускать активити через кнопку на экране "оплата", то баг не воспроизводится
